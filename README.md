# GREEN-API Chat

Простой веб-чат для отправки и получения текстовых сообщений через
[GREEN-API](https://green-api.com) (WhatsApp). Тестовое задание на позицию
Frontend-разработчика React.

## Стек

- React 19 + TypeScript
- Vite
- Без бэкенда — все запросы к GREEN-API идут напрямую из браузера

## Как это работает

1. На экране входа вводятся `idInstance` и `apiTokenInstance` вашего
   инстанса GREEN-API.
2. Пользователь вводит номер телефона получателя — создаётся чат.
3. Отправка сообщений — обычный POST-запрос к методу `SendMessage`.
4. Получение сообщений — приложение в фоне постоянно опрашивает метод
   `ReceiveNotification` (это называется polling: сервер сам ждёт до 5 секунд
   и возвращает сообщение, если оно появилось). После обработки каждое
   уведомление удаляется через `DeleteNotification`, иначе оно бы приходило
   повторно.

## Локальный запуск

Понадобится Node.js версии 18 или новее.

```bash
git clone <ссылка на ваш репозиторий>
cd green-api-chat
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

## Настройка инстанса GREEN-API (перед первым запуском)

1. Зарегистрируйтесь на green-api.com — на бесплатном тарифе сразу выдаётся
   тестовый инстанс.
2. В консоли инстанса включите настройки:
   - Получать уведомления о входящих сообщениях
   - Получать уведомления о сообщениях, отправленных с API
3. Отсканируйте QR-код инстанса в приложении WhatsApp на телефоне (Связанные
   устройства -> Привязать устройство) — это активирует инстанс.
4. Скопируйте idInstance и apiTokenInstance из консоли — введите их на
   экране входа приложения.

## Структура проекта

```
src/
  api/greenApi.ts            — запросы к GREEN-API (отправка/получение/удаление)
  hooks/useMessagePolling.ts — фоновый цикл получения новых сообщений
  components/
    LoginScreen.tsx          — экран входа
    ChatScreen.tsx           — экран чата
  types.ts                   — общие типы данных
  App.tsx                    — переключение между экранами, хранение сессии
```
